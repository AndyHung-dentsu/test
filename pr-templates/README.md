# Github PR 範例

## 使用方式
放置於專案目錄 `.github/PULL_REQUEST_TEMPLATE` 目錄下，於 github 開 PR 時即可選擇範本

## 檔案說明
|  PR 場景   | 檔案  |
|  ----  | ----  |
| 功能分支 => master  | [feature-pr-template](templates/feature-pr-template.md) |
| master => production  | [release-pr-template](templates/release-pr-template.md) |
| release => production  | [release-pr-template](templates/release-pr-template.md) |
| production => master  | [back-merge-pr-template](templates/back-merge-pr-template.md) |
| hotfix => production  | [hotfix-pr-template](templates/hotfix-pr-template.md) |
| hotfix => master  | [back-merge-pr-template](templates/back-merge-pr-template.md) |
| prd => master  | [prd-pr-template](templates/prd-pr-template.md) |
